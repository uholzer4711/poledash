Volvo Developer API — official sibling source

Polestar runs on Volvo's connected-car platform. Volvo publishes some APIs publicly at developer.volvocars.com/apis. Practical reality for Polestar 2 / EX40:

APIPS2 / EX40 supportWhat it gives
Connected Vehicle v2 Legacy Volvos only — no PS2 / Recharge Door/window/lock, fuel, engine, climate (legacy ICE)
Extended Vehicle v1 Same — legacy only Distance, fuel level, windows, lights
Energy v1 Works with PS2 VINs SoC, target SoC, charging system status, charging connection

Energy-API endpoint shape: GET https://api.volvocars.com/energy/v1/vehicles/{vin}/recharge-status[/<subresource>]
Auth: OAuth2 bearer + vcc-api-key header. Test tokens on the dev portal after Volvo-ID login; production needs Volvo partner approval (callback URL etc.). Rate limit: 100 req/min per (Volvo-ID × Client-ID).
Sample code: github.com/volvo-cars/developer-portal-api-samples

Trade-off: documented + stable, but requires registration. Our reverse-engineered consumer route gets ~10× more fields (gRPC battery, target, telematics) without paperwork — at the cost of breaking when Polestar reshuffles.
